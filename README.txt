==================================

Contents
- index.html: Home
- about.html: About the firm and partners
- services.html: Overview of services
- gst-services.html: GST services
- income-tax.html: Income tax services
- bookkeeping.html: Accounting and bookkeeping
- contact.html: Contact details and enquiry form
- assets/css/style.css: Responsive styles
- assets/js/site.js: Mobile navigation and enquiry email helper
- robots.txt and sitemap.xml: Basic crawler files

DEPLOYMENT (CLOUDFLARE PAGES)
1. Extract this ZIP.
2. In Cloudflare, open Workers & Pages > Create application > Pages.
3. Choose Direct Upload / Upload assets (wording may vary).
4. Upload the extracted website folder contents, or create a ZIP from the extracted contents if prompted.
5. Deploy. No build command is required; the site is plain HTML, CSS and JavaScript.
6. Add your custom domain in the Pages project settings after deployment.

NOTES
- No domain name was supplied, so canonical URLs have not been invented. Add your absolute website URLs to sitemap.xml after connecting your custom domain.
- The enquiry form uses the visitor's default email application (mailto); it does not store or transmit enquiries to a server.
- Confirm all business details, service scope and current filing requirements before publishing.
